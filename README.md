Participantes: Gabriel Augusto Pereira, João Vitor Calmon e Weverton Gomes da Silva.

## Algumas recomendações para o controle de versionamento

* Sempre deixe a branch `main` funcionando;
* Faça branches com propósitos não tão gerais e de pouca duração;
* Faça pull da `main` com frequência;
* NÃO modularize em diferentes arquivos - orientação do professor;
* Se possível, faça pull request e espere a revisão de outra pessoa;
* Faça mensagens de commit claras.
